# The Micro_Invasion

An AR exposure experience that makes invisible microplastic contact visible across the body and surrounding space.

## Concept vs Built

The implemented interaction uses tracked-hand proximity to a virtual trigger: tracked hand → distance → threshold → interaction. It is not object detection. World-mesh development focused on performance and particle-density tuning.
